# activate-ditto
Script to activate [Ditto](https://sabrogden.github.io/Ditto/) when installed under [winehq](https://www.winehq.org/).

## Archived

You can easy open Ditto clipboard by set this command to any shortcut you prefer (standard is Ctrl+backslash):
`wine "C:\Program Files\Ditto\Ditto.exe" /Open`

Enjoy.
